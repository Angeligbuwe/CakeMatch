# CakeMatch

## Project Purpose

CakeMatch is a cake planning website that recommends a suitable cake size
based on the number of guests and the customer's preferences. It helps
customers who aren't sure which cake size will serve their guests, or who
might forget to mention important details when ordering a custom cake.

## MVP Features

1. The customer selects the celebration type.
2. The customer enters the number of guests.
3. The customer chooses a preferred cake flavour and design.
4. CakeMatch recommends a suitable cake size.
5. The website displays an order summary.

## Technology

- TypeScript
- Jest (with ts-jest) for testing

## Testing

Run the test suite with:

```
npm test
```

## Coding Guidelines

- Keep the code simple and readable — this is a beginner-friendly project.
- Prefer small, focused functions over large ones.
- Add a test for new logic, especially the cake size recommendation rules.
- Avoid adding new dependencies unless necessary.
- Avoid over-engineering; only build what the current feature needs.
